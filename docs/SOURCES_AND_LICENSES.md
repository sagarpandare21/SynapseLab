## 3. Project Data

The experiment uses small predefined numerical pattern vectors.

Examples:

CAT:
[1, 1, 0, 1, 0, 0, 1, 0]

DOG:
[1, 0, 1, 1, 0, 1, 0, 1]

BIRD:
[0, 1, 1, 0, 1, 0, 1, 1]

CAR:
[1, 0, 0, 1, 1, 1, 0, 0]

These vectors were created for the educational simulation.

They are not biological measurements and are not taken from a neuroscience dataset.

License/status:
Original project data.
