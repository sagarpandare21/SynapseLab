# SynapseLab — An Interactive Memory Lab

> **Can a memory live in a connection?**

SynapseLab is an interactive web-based educational simulation that demonstrates simplified computational ideas related to **synaptic plasticity, learning, memory, recall, and interference**.

The application allows a learner to select a pattern, learn it, recall it, introduce interference, and observe how the simulated synaptic state changes.

**Important:** SynapseLab is an educational computational model. It does not claim to reproduce the complete biological mechanisms of human memory.

---

## 1. Project Overview

Learning and memory are associated with changes in the strength and organization of connections between neurons. SynapseLab provides a simple interactive representation of this idea using numerical synaptic weights.

The learner can:

1. Select a pattern.
2. Learn the selected pattern.
3. Recall the stored state.
4. Apply interference.
5. Observe the change in synaptic weights.
6. Compare memory strength before and after interference.
7. Reset and repeat the experiment with another pattern.

The current application contains four predefined patterns:

- CAT
- DOG
- BIRD
- CAR

---

## 2. Problem Being Addressed

Concepts such as synaptic plasticity and memory can be difficult to understand through theory alone.

SynapseLab addresses this by providing a browser-based interactive experiment in which the learner changes the state of the model and immediately observes the consequence.

The project is intentionally designed so that it is not just a static presentation, PDF, or video. The learner can change the selected pattern and perform different experiment operations.

## 5. Interactive Experiment

The main experiment follows this workflow:

```text
Choose Pattern
      ↓
Learn
      ↓
Store Synaptic Weights
      ↓
Recall
      ↓
Calculate Recall Strength
      ↓
Interfere
      ↓
Modify Synaptic Weights
      ↓
Calculate New Strength
      ↓
Display Result
```

### Step 1 — Choose a pattern

The learner selects CAT, DOG, BIRD, or CAR.

Each pattern contains a numerical vector representing a simplified synaptic state.

Example:

```text
CAT
[1, 1, 0, 1, 0, 0, 1, 0]
```

### Step 2 — Learn

The selected vector is stored as the current state of the model.

### Step 3 — Recall

The application calculates a simplified recall-strength value from the current weights.

The current implementation uses the average absolute weight:

```text
Recall Strength =
Sum of absolute weights / Number of weights
```

### Step 4 — Interference

The experiment applies a simplified interference operation:

```text
New Weight = Old Weight × 0.6
```

Therefore, 60% of the previous weight remains.

The resulting simulated interference is:

```text
100% − 60% = 40%
```

### Step 5 — Reset

The learner can reset the experiment and start again.

---

## 6. Why the 40% Result Should Not Be Misinterpreted

The 40% interference value is generated by the mathematical rule used in this simplified simulation.

It is **not**:

- a measurement of human memory,
- a clinical result,
- a biological measurement,
- or a claim that human memories lose exactly 40% of their strength.

It is a property of the computational model.

---

## 7. Scientific Motivation

Synaptic plasticity is an important research area in neuroscience because changes in synaptic connections are associated with learning and memory.

SynapseLab uses this biological motivation as inspiration but deliberately simplifies the biological system into a small computational model.

The project should therefore be interpreted as an educational demonstration rather than a complete neuroscience simulator.

Install:

## 13. Model Limitations

SynapseLab has several important limitations:

- It uses a simplified representation of neurons and synaptic weights.
- It is not a complete biological brain simulation.
- The interference operation uses a fixed mathematical rule.
- Only a small number of predefined patterns are included.
- The model does not reproduce the complete mechanisms of biological memory.
- The numerical results are properties of the simulation.

Therefore, the application should be used for education and conceptual demonstration rather than biological prediction.

## 18. Evidence vs Simulation

### Published scientific evidence

Research supports the importance and complexity of synaptic plasticity in learning and memory.

### SynapseLab simulation

SynapseLab uses a simplified computational representation to make these concepts interactive.

The project therefore distinguishes between:

```text
Scientific Evidence
        ≠
Simulation Result
```

The simulation's 40% interference result should not be presented as a biological measurement.

SynapseLab demonstrates how a simple computational model can make abstract ideas about learning, synaptic weights, memory, and interference easier to explore.

The learner can actively change the pattern and experiment state rather than simply reading a static explanation.

The project is intentionally transparent about its limitations: it is an educational simulation inspired by neuroscience research, not a complete model of biological memory.
